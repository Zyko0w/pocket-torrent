Pocket Torrent — installation
=============================

1. Double-cliquer sur « PocketTorrent_<version>_x64-setup.exe ».
   Pas besoin de droits administrateur : le logiciel s'installe pour le compte Windows en cours.

2. Si Windows affiche « Windows a protégé votre ordinateur » :
   cliquer sur « Informations complémentaires », puis « Exécuter quand même ».
   (Le programme n'est pas signé par un certificat payant, d'où cet avertissement.)

3. Lancer « Pocket Torrent » depuis le menu Démarrer ou le raccourci du Bureau.

Configuration nécessaire : Windows 10 ou 11, 64 bits.

Désinstallation : Paramètres Windows > Applications > Pocket Torrent > Désinstaller.
Si le tunnel VPN intégré a été installé, le retirer d'abord : Réglages > VPN > Désinstaller.
